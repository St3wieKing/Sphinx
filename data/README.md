# Market Data Contract

No market dataset is committed. Synthetic data generated by the CLI is for engineering validation only and must never be cited as strategy performance.

## CSV

```csv
timestamp,open,high,low,close,volume,symbol,interval_seconds
2024-01-08T05:00:00Z,16800.00,16801.25,16799.50,16800.75,412,NQ,120
```

Required: `timestamp,open,high,low,close`. Timestamps must include an offset; UTC `Z` is recommended. Rows must be strictly increasing and represent completed bars. `volume`, `symbol`, and `interval_seconds` are optional.

## Required external manifest

Store alongside private/vendor data, not in Git if licensing prohibits it:

```json
{
  "dataset_id": "...",
  "vendor": "...",
  "acquired_at": "...",
  "contracts": ["NQH24"],
  "raw_timezone": "America/Chicago",
  "normalized_timezone": "UTC",
  "bar_timestamp_semantics": "open",
  "rollover_rule": "...",
  "adjustment": "none|difference|ratio",
  "holiday_calendar": "...",
  "missing_bar_policy": "reject/no interpolation",
  "sha256": "...",
  "known_issues": []
}
```

For optional SMT, ES must use the same interval, timestamp semantics, trading calendar, and completed timestamps. Missing ES timestamps are left missing; no future/backfilled comparison is permitted.

## NQ/MNQ tooling

`download-research-data` knows about a public CC0 NQ one-minute starter dataset, but its continuous-series rollover must be verified. `normalize-data` converts external one-minute exports into the strict two-minute contract, drops incomplete buckets, and emits a provenance/hash manifest. See [`docs/nq_mnq_deep_backtesting.md`](../docs/nq_mnq_deep_backtesting.md).

NQ and MNQ need separate instrument costs and point values. They follow the same underlying index and are not independent evidence of an edge.
